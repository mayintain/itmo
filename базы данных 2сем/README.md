# Базы данных

Материалы и лабораторные работы по дисциплине **«Базы данных»**.

Курс был посвящён проектированию, реализации и оптимизации реляционных баз данных на примере PostgreSQL. В лабораторных работах рассматривался полный цикл работы с базой данных: от анализа предметной области и построения модели до написания SQL-запросов, нормализации схемы, создания триггеров и анализа планов выполнения запросов.

## Что было изучено

В рамках курса были освоены:

- анализ предметной области;
- выделение сущностей, атрибутов и связей;
- построение инфологической модели;
- построение даталогической модели;
- реализация схемы базы данных в PostgreSQL;
- создание таблиц с первичными и внешними ключами;
- использование ограничений целостности;
- заполнение таблиц тестовыми данными;
- написание SQL-запросов;
- соединение таблиц через `JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `INNER JOIN`;
- фильтрация данных через `WHERE`;
- группировка и агрегация через `GROUP BY`, `HAVING`, `COUNT`, `AVG`, `MAX`;
- использование подзапросов, `EXISTS` и `NOT EXISTS`;
- описание функциональных зависимостей;
- проверка схемы на 1НФ, 2НФ, 3НФ и BCNF;
- анализ возможной денормализации;
- написание функций и триггеров на PL/pgSQL;
- подбор индексов для SQL-запросов;
- анализ планов выполнения через `EXPLAIN ANALYZE`;
- понимание разницы между `hash` и `btree` индексами.
