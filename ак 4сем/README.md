# Архитектура компьютера

Материалы и лабораторные работы по дисциплине **«Архитектура компьютера»**.

Курс посвящён устройству вычислительных платформ: тому, как они работают, какие сервисы предоставляют разработчикам и почему современные компьютерные системы устроены именно так. Основной акцент сделан на понимании архитектурных решений, их исторических причин, ограничений и последствий.

## Зачем этот курс

Курс помогает понимать компьютерные системы не только с точки зрения написания кода, но и с точки зрения того, как этот код исполняется на разных уровнях: от ISA и процессора до памяти, ввода-вывода, параллелизма и взаимодействия аппаратной и программной частей.

Это полезно для разработки в любой области — frontend, backend, mobile или embedded, потому что позволяет лучше понимать ограничения платформы, причины неожиданных ошибок, влияние архитектурных решений на производительность и поведение программ.

После курса разработчик лучше понимает:

- как устроены вычислительные платформы, на которых работают приложения;
- как процессор, память, кэш, ввод-вывод и параллелизм влияют на выполнение программ;
- почему одинаковый код может по-разному вести себя на разных платформах;
- какие последствия могут иметь выбранные технические решения;
- как делать более обоснованные предположения о работе библиотек, фреймворков, сервисов и системного окружения.

Идея курса — убрать «магическое мышление» в отношении компьютерных систем и дать базу, которая помогает разработчику принимать решения осознанно, а не только на уровне конкретного языка программирования или фреймворка.

## Содержание

В папке собраны реализации и материалы по лабораторным работам, связанным с разными учебными архитектурами и моделями вычислений.

## Лабораторная работа №3. Опыты

В рамках лабораторной работы реализованы программы для нескольких архитектур:

- `acc32-count-divisors` — подсчёт количества делителей числа на архитектуре acc32;
- `f32a-binary-palindrome` — проверка 32-битного двоичного представления числа на палиндромность на архитектуре F32a;
- `risc-iv-reverse_string_cstr` — переворот C-строки на архитектуре RISC-IV;
- `m68k-stack-based-calculator` — стековый калькулятор на архитектуре M68K;
- `vliw-iv-fnv32_1_hash` — вычисление FNV-1 32-bit hash на архитектуре VLIW-IV;
- `m68k_scheme` — схема для задания по M68K.

## Используемые инструменты

Для проверки программ используется `wrench` и Docker-образ:

```bash
ryukzak/wrench:latest
```

Типовой запуск программы:

```bash
docker run --rm -it \
  -v "$PWD":/work \
  -w /work \
  ryukzak/wrench:latest \
  wrench <source-file> --isa <isa-name> -c <config-file>
```

Конкретные команды запуска указаны в `README.md` внутри каждой папки с заданием.

## Архитектуры

В работах используются разные модели вычислений:

- **acc32** — аккумуляторная архитектура;
- **F32a** — стековая архитектура, вдохновлённая Forth-подходом;
- **RISC-IV** — RISC-подобная архитектура;
- **M68K** — архитектура семейства Motorola 68000;
- **VLIW-IV** — архитектура с явно выраженным параллелизмом команд.
